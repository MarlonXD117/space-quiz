# Órbita

Órbita es un quiz en español sobre exploración espacial. Responde diez preguntas de opción múltiple, consulta la explicación de cada respuesta y descubre tu puntuación final.

## Ejecutar en local

No necesitas instalar dependencias ni iniciar un servidor. Descarga o clona el repositorio y abre `index.html` en un navegador.

## Publicación

El sitio se publica en GitHub Pages desde la rama predeterminada mediante GitHub Actions. Cada cambio que se integra en esa rama inicia un nuevo despliegue.
